# Contributing

Fontbend is a small project with a clear direction: a free font maker that runs in the browser, with no accounts. Product and design decisions are made by its maintainer.

## Issues

Use one of the issue forms:

- **Bug report:** what you did, what you expected and what happened, with your browser and operating system. Attach a font file only if its license allows sharing it.
- **Translation:** a wrong or missing text in the interface, or a new language.
- **Idea:** something you would like Fontbend to do. Every idea is read, but not every idea will be built.

If you use an AI tool to write an issue, read it before posting. You are responsible for what you post.

## Pull requests

Pull requests are open to maintainers only for now. If you have a fix in mind, describe it in an issue.

## Behavior

Be kind and stay on topic. Spam, repeated pings and abuse lead to a ban.
