# Contributing

Fontbend is a small project: a free font maker that runs in the browser, with no accounts. Its maintainer makes the product and design decisions.

## Issues

Use one of the issue forms:

- **Bug report:** what you did, what you expected and what happened, with your browser and operating system. Attach a font file only if its license allows sharing it.
- **Translation:** a wrong or missing word or sentence in the interface, or a new language.
- **Idea:** something you would like Fontbend to do.

If you use an AI tool to write an issue, read it before you send it. You are responsible for its content.

## Pull requests

Pull requests from outside the project aren't accepted for now. If you have a fix in mind, describe it in an issue.

## Behavior

Be kind and stay on topic. Spam, repeated pings and abuse lead to a ban.
